# SttS データ工房

本体ソースを参照して設定を編集する独立したローカルツールです。本体へ組み込むモジュールではありません。

## 起動

リポジトリ直下でnpm installを済ませ、start.cmdを実行してください。あるいはこのフォルダでnpm startを実行します。コンソールに表示されたローカルURLをブラウザで開きます。ブラウザは自動起動しません。

## 利用と保守

- [操作・保存・ビルド失敗時の復旧](../../docs/manual/editor.md)
- [設定項目別ユーザーズマニュアル](../../docs/manual/README.md)
- [内部設計と適用トランザクション](../../docs/data-editor-design-ja.md)

下書き保存と本体適用は別操作です。「ビルド実行」「ビルドして適用」「ビルドせず適用」を選べます。ビルド付き適用で失敗した場合はソースを復元し、下書きを保持します。外部変更との競合時は自動上書きしません。詳細と保存場所は操作マニュアルを参照してください。

開発時のロジック検証はこのフォルダでnpm test。本体の型・バンドル確認はリポジトリ直下でnpm run build。画面操作・表示の確認はユーザーへ依頼します。
