# BGM・音量

## 音源を追加する

`bgm/`直下にMP3・OGG・WAVを置きます。拡張子を除いたファイル名が曲IDです。日本語・空白を含む名前も使えます。同じIDの拡張子違いファイルは置かないでください。ExtraのBGM一覧には最初から全曲が出ます。追加・改名した素材はゲームの再ビルドに含めます。

Extraは`BGM_TRACKS`の定義順に、左から右へ3列で曲を並べます。現在の18曲は1画面に収まります。未登録の音源は登録曲の後ろに並びます。曲名を押すと再生が始まり、再生中の曲の背景色が変わります。下部のプレイヤーで頭出し・再生・停止を操作できます。

ファイルパスをデータへ記載する必要はありません。`bgm/`はGit管理外です。音源の配布・バックアップはソースとは別に行ってください。`bgm/_original/`の比較用音源はゲームの検出・配布対象外です。

曲の改名時は音源ファイル名、`BGM_TRACKS`のキー、場面・会話の曲IDを揃え、旧名を曲評価コメントの後ろに括弧書きで残します。既存セーブの曲IDも引き継ぐ場合は、[saveCompatibility.ts](../../src/models/saveCompatibility.ts)の`RENAMED_BGM_IDS`に旧名→現行名を登録します。再改名する場合は過去の旧名も最新名を直接指すように更新してください。

## ループ

[bgm.ts](../../src/data/bgm.ts)の`BGM_TRACKS`で曲IDをキーに指定します。未登録の曲は音源全体をループします。

| 項目 | 必須 | 単位・動作 |
| --- | --- | --- |
| loopStart | 登録する場合は必須 | 0以上の秒数、小数可。初回は0秒から、2周目以降はこの秒へ戻る |
| loopEnd | 任意 | loopStartより後、音源の長さ以下の秒数。省略は音源末尾 |

位置はデコード後の音声先頭が基準です。イントロを含む音源1つにループ開始位置を設定すれば、イントロ専用・ループ専用の2ファイルは不要です。ループをイベントやタイマーで繋ぎ直さず、音声エンジンのループ区間で再生します。

ツールの「BGM・音量・場面割当」→`BGM_TRACKS`→曲を選び、「頭から試聴」「ループ境目を確認」で確認できます。境目確認は設定した末尾の4秒前からです。フォームの下書き値を使い、試聴中に値を変えた場合は再生ボタンを押し直してください。ゲームの音量設定には影響しません。試聴時に実際の音声長も表示し、長さを超える区間を拒否します。

## 場面への割り当て

同じファイルの`BGM_BINDINGS`に設定します。値は曲IDまたは`null`（停止）。各マップ自体は必須ですが、空の`{}`で構いません。

| 設定 | キー・省略時の動作 |
| --- | --- |
| title | タイトルの既定曲。必須 |
| battleDefault | 未割当の戦闘曲。必須 |
| battleThreats | 戦闘開始時の脅威度（1以上の整数）→曲 |
| stageBattles | ステージ番号→脅威度→曲。共通のbattleThreatsより優先 |
| stageRoutes | ステージ番号→道中曲。道中画面は未実装。呼出し側を追加する際の設定枠 |
| eventBattles | EVENT_BATTLESのキー→曲。通常戦闘設定より優先 |
| conversations | CONVERSATIONSのキー→開始時の曲。未指定なら直前の曲を継続 |

さらに各会話ページの`bgm`（任意）で上書きできます。曲IDで選曲、`null`で停止、項目自体を省略すれば継続します。同じ曲IDを再指定しても先頭へ戻りません。ロード時は保存された曲を先頭から再生します。

戦闘内の会話終了後は会話前の曲に戻ります。同じ曲を維持した会話では再生を継続します。報酬画面は戦闘曲を維持します。Extraで試聴した曲は、Extraの別タブ・タイトルへ戻っても維持します（停止も維持）。この試聴選択は起動中のみで、ゲームの場面ごとの割り当てを変更しません。

## 音量・障害時

ゲームの設定→音量設定、またはタイトル・Extraの音量設定で変更します。0はミュート、以降は整数段階です。実音量はマスター×BGMで決まります。非アクティブ時の停止を有効にすると、戻った際に同じ位置から再開します。設定はランセーブと別に自動保存します。

`AUDIO_SETTINGS`の項目は定数を定義する際すべて必須です。

| 項目 | 意味 |
| --- | --- |
| defaultMaster / defaultBgm | 0～maxVolumeの整数。ユーザー設定未保存時の初期値 |
| pauseOnBlur | 非アクティブ時に停止するかの初期値 |
| maxVolume | 最大の音量段階。正の整数。設定位置数はこれにミュートを加えた数 |
| fadeOutSeconds | 曲変更時の旧曲フェード秒数。0以上。新曲はフェードインなし |
| retryCount | 初回の失敗に追加する再試行回数。0以上の整数 |
| retryDelayMs | 再試行間の待ち時間ms。0以上 |
| loadTimeoutMs | 取得タイムアウトms。正の数 |

読み込みに失敗してもゲームは続行します。通知後、Extraの再生ボタンで再試行できます。Ctrl早送りでは音程・再生速度を変えません。ブラウザの初回再生はクリック等による音声許可が必要です。exeの起動直後からの再生については[音声設計](../audio-design-ja.md)のネイティブ出力移行を参照してください。
