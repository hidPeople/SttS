# カード説明の内部設計

[文書一覧](README.md) / [作者向けの記法](manual/cards.md)

## 単一の生成経路

[cardDescription.ts](../src/models/cardDescription.ts) がカード入力に由来する情報を説明へ変換する。手札、山札・捨て札、報酬、拡大表示、編集ツールで同じ生成器を使う。文章テンプレートは [cardText.ts](../src/data/cardText.ts) に置く。

基本値表示と手札表示の差は、異なる説明文を持つのではなく、同じ効果に渡す値の解決文脈で表す。手札では補正後の値と基礎値を比較して数値だけを強調する。乱数は消費せず、未確定量は範囲で表す。

## 生成の段階

1. conditions、effects、任意description、カード挙動を表示要素へ変換する。
2. description内の対象・効果種別参照またはtextId参照を解決する。
3. 任意文で使用済みの効果本文を自動文から除外し、未参照の必要補足を残す。
4. textOrderまたは入力プロパティ順で説明を並べる。
5. 不動・消滅・一時カードを専用フッターへ集約する。
6. 表示側で用語範囲、強調部分、置換後の折り返しを処理する。

textOrderは効果実行順から独立する。繰り返し・確率・対象が違う効果の参照を、曖昧なamount一つへまとめない。

## 予測の境界

arousal段階の説明は現在状態からの変更結果を予測するが、実際の状態を書き換えない。カードの特殊対象・回数は戦闘側の既存解決器から取得する。全連鎖反応の先行実行はしない。

プレイヤーEP自傷の予測0は自動文を隠す。基礎表示の固定小数ダメージは切り捨て注記を追加する。任意文内の固定の文章まで自動削除しない。

## 描画・用語

[cardText.ts](../src/ui/cardText.ts)、[cardTermHover.ts](../src/ui/cardTermHover.ts)、[textLayout.ts](../src/ui/textLayout.ts) が共有される。状態異常とシステム用語を別種として装飾・Tipsへ接続する。言語切替後の名称で用語領域を作る。

文字解像度は [cardTextResolution.ts](../src/models/cardTextResolution.ts) とUI側で表示倍率に対応付ける。配置・ホバー・拡大画面ごとに文章生成を複製しない。

## 拡張時

カード外観は [cardPresentation.ts](../src/ui/cardPresentation.ts) を全表示箇所で共有する。四辺同幅のレアリティ縁、その内側のカード種別色の角丸飾り、画像、名前・説明パネルの順で構成する。透明なRectangleは入力専用であり、輪郭を描かない。選択光も角丸に追従する。

[cardArtwork.ts](../src/ui/cardArtwork.ts) は画像URLだけをビルド時に収集し、表示要求のあった画像のみ読み込む。元画像座標からの配置・回転、画像四辺のフェード、角丸内側の切り抜きをCanvasに合成し、設定と寸法ごとのテクスチャとして共有する。画像の加工は毎フレーム行わず、元ファイルは変更しない。ワールド座標のマスクを追加しないため、カード移動・拡縮・山札スクロールのマスクと干渉しない。カード破棄後の読み込み完了で画像を復活させない。

戦闘IDによる画像選択は [cardArtwork.ts](../src/models/cardArtwork.ts) が担当し、戦闘ロジックに条件分岐を追加しない。カードID_戦闘ID.png、カードID_normal.pngの順に存在する画像を探し、実際に選んだ画像の戦闘IDで配置を引く。画像がなければ黒地のまま名前・説明と入力を維持する。配置未登録なら中央・自動倍率を使う。配置・レアリティ色の正本は [cardAppearance.ts](../src/data/cardAppearance.ts)。

外部編集ツールは [cardArtworkCanvas.ts](../src/ui/cardArtworkCanvas.ts) と [cardArtworkGeometry.ts](../src/models/cardArtworkGeometry.ts) の純粋な描画・計算を参照する。ツール側が許可済みの本体モジュールをブラウザ用に変換・配信し、本体からツールへの依存は持たない。設定値は下書きの構文木から読み、下書きコードを実行しない。プレビュー調整は明示的な下書き反映までメモリ内に保持し、選択したカードの編集済み戦闘区分だけを書き換える。

EffectKind追加時は、実行器だけでなくCARD_EFFECT_TEXTと参照フィールド、基本値／予測値、編集ツールの基礎プレビューを揃える。条件追加も使用可否判定と説明生成を一緒に確認する。文法と対応表の正本はマニュアルに置く。
