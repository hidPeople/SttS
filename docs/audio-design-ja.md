# 音声の責務

設定の正本は[data/bgm.ts](../src/data/bgm.ts)、設定方法は[音声マニュアル](manual/audio.md)。音源URLは`platform/bgm.ts`がViteの静的globから収集する。URL一覧の生成は全曲のダウンロード・デコードを意味しない。サブディレクトリは対象外。将来のexeでも同じビルド済みURLを利用でき、作業ディレクトリに依存しない。

`models/bgm.ts`の`BgmPlayer`はSceneを跨いで1つ。現在の選曲、ロードの世代番号、停止、再試行、旧曲のフェード、Extraのメニュー用選曲を管理する。Sceneの休止やゲーム時間倍率から独立する。異なる曲のロードと旧曲のフェードは並列だが、旧曲停止後に新曲を開始する。同じIDのロード・再生中は重複要求を無視し、明示した頭出し・ロード復帰だけ再スタートする。

要求が更新されたら通信を中断し、デコードが遅れて完了しても古い要求の音を開始しない。Web Audioのデコード自体は中断できないため、その結果は世代番号で破棄する。全曲のPCMキャッシュは保持せず、通常は再生中の1曲、遷移中は新旧の音声バッファを使用する。停止後は音声ノードを切断してバッファ参照を解放する。再試行尽きの場合は通知し、ゲーム本体の進行を阻害しない。

`BgmOutput`が出力境界。Web版の`WebBgmOutput`は専用AudioContext・マスターGain・曲ごとのGain・ループ付きAudioBufferSourceNodeを使用する。ループ境目は音声時計で処理し、setTimeoutで次の音声を繋がない。フェード終了後のノード解放だけ実時間のタイマーで行う。非アクティブ時は専用Contextをsuspendし、再開で位置を保持する。Phaserの演出・Ctrl速度を音声時計へ適用しない。

ユーザー設定の`audio`はマスター・BGM音量とpauseOnBlur。値変更の購読で音量・停止状態を反映し、毎フレーム設定を読み直さない。今後ボイス・SEを足す際はこの名前付き設定へチャンネルを追加し、BGMのループ・選曲とは別の出力ノードを用意する。ランセーブの`bgm`は曲ID/nullのみ。未指定の旧セーブは場面の規定値を使い、再生位置は保存しない。

会話は初期ページまでのbgm指示を解決し、以降はページ進入時だけ適用する。言語変更・背景再描画では再選曲しない。セーブ復帰時は保存曲を優先する。戦闘内会話のみ、完了時に開始前の選曲を復元する。Extra試聴の選択はメニュー用に別保持し、ゲーム場面の曲変更とは混同しない。

## exe化時の作業

ブラウザの自動再生制限はWebViewへ包むだけで必ず解除されるとは保証しない。Tauriホストのネイティブ音声エンジンで`BgmOutput`を実装し、起動時クリックなしの再生を保証する。Scene・曲ID・保存形式はそのまま使用し、PCMループ区間、音量、フォーカス休止、音声ノード解放をネイティブ側へ対応付ける。`platform/bgm.ts`の生成箇所で出力実装を差し替える。既定のWebView2挙動や開発用自動再生フラグには依存しない。

インストーラー配布時には音源の同梱・ライセンス確認、ユーザー別設定保存アダプター、コーデックと隙間なしループ、初回起動・非アクティブ復帰を実機確認する。現時点ではexeホストを実装していないため、この作業は未完了。
