# AI文章生成セットの使い方

このセットは、リポジトリを読めないAIへSttSの文章仕様を渡すためのものです。フレーバーとノベル会話は生成ガイドを分け、それぞれ `flavors: {...}` と `会話ID: [...]` を最低出力単位にします。新規の例文と生成指示は非露骨な範囲です。別途、指定された現行の正式文章2件を改変せず参考資料として収録しています。

## AIへ渡すもの

1. [プロジェクト指示](00-project-instructions.txt) の全文を、AIのプロジェクト指示欄へ貼ります。
2. 下記5ファイルを知識として添付します。AIは依頼からモードを選び、対応する専用ガイドを優先します。
3. 通常の依頼では、場面・状態・雰囲気・流れを伝えれば十分です。既存ブロックがなくても新規提案を作り、接続や最後の調整はプロジェクト側で行えます。既存候補を正確に保持した置換が必要なら、そのブロックも渡します。

| 添付ファイル | 役割 |
| --- | --- |
| [共通設定とモード選択](01-authoring-knowledge.md) | 人物設定・日英の書式だけを共通化 |
| [フレーバー生成ガイド](04-flavor-guide.md) | flavors全体、条件、イベント、候補選択、Strikeの完成例、Seductionの正式flavors全文 |
| [会話生成ガイド](05-conversation-guide.md) | 会話IDと全ページ、speaker、固定2欄、脚本の前提、末尾のbackgroundDim、prologueAfterBattleの正式ブロック全文 |
| [現行登録と入力契約](02-current-reference.md) | 必要なID・型を引く辞書 |
| [設定マニュアル保存版](03-manual-snapshot.md) | 詳細確認用の原文保存。生成手順書ではない |

フレーバー専用のAIなら05、会話専用なら04を省略できます。共通辞書と原文保存版は、参照漏れを防ぐため両モードで共有します。

Markdownをそのまま添付する構成です。PDF専用の機能やリポジトリへのアクセスは前提にしていません。会話ページの `portrait: '', background: ''` は用途の説明をせず、常に書く固定フォーマットとします。暗くする指定はbackgroundDimで本文ブロックへ含めます。

## 依頼例

```text
Strikeを使用する時のフレーバーを作って。
普段は生意気に強がるが、HP25%以下では焦りが出るように。
口が塞がっている場合は明示した心の声にする。
必要な違いだけ条件分岐にして、flavors全体を出して。
```

```text
ノベルパートの敗北会話を作って。
出口へ向かうが力尽きる→強がる→動けず諦める、の流れで6ページ。
飢えていて動けない状態を前提にして。
最後のページで背景を暗くして終了。
会話IDを含むブロックを出して。
```

## 収録範囲

- フレーバー64イベント、条件22種類、状態54種類、演算子・対象・話者・全ログ種別。
- イベント別の値と配置先、日英・引用符・置換・抽選・表示抑止。
- 会話全項目、背景遷移の仕様、敗北時の接続、登録済みカード・敵・レリック・会話ID。
- 最新の人物設定。一人称は「あたし」で統一し、通常の地の文は三人称。
- 関連マニュアル7章の全文保存と、実装から補足した制限。

## 更新と検証

自動抽出資料を更新する場合、リポジトリのルートで実行します。

```sh
node tools/docs/generate-authoring-reference.mjs
node tools/docs/generate-authoring-reference.mjs --check
node tools/docs/check-authoring-knowledge.mjs
```

生成器は02・03の全体と、04・05の末尾にある正式記載例だけを更新します。正式記載例はソースから直接抽出し、本文・条件・並び順・設定値を保持します（改行コードのみLFに統一）。00・01と04・05のその他の部分は人物設定・各モードの指針・実行器の意味を確認して更新します。鮮度チェックは参照元の変更と正式記載例の一致を検証しますが、ナレッジの意味を自動修正しません。検証は各ガイドのTypeScriptブロックを適切な型で囲って行い、ゲームデータへ書き込みません。正式記載例も型検証の対象ですが、新規生成用の固定空欄チェックからは除外します。

検証コマンドが成功しても、新たにAIが出力する未知の文章や条件まで動作保証するものではありません。新しい出力は実際の貼り付け先で型と条件を確認してください。

既存ゲーム本文・状態・バランスはこの文書セットで変更しません。
