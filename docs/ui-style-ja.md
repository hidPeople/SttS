# クレヨンUIの描画方針

## 共通部品

`src/ui/crayon.ts` の `CrayonPatch` を名前・行動予告・ボタンの背景に使用する。白いクレヨンの塗りをCanvasで描画し、透明部分を保持して着色する。中央は文字の可読性を保てる濃さにし、輪郭の欠け、斜めの塗り端、細かな塗り残しで四角いベタ塗りを避ける。

生成・再生成するたびに筆跡の始点・終点などをランダムに決め、同じ寸法でも形が変わる。暗号乱数で初期化したローカルな生成器を使い、ゲームの抽選結果に影響を与えない。背景ごとに出力用CanvasTextureを1枚持ち、再生成・演出中も再利用し、背景の破棄時に解放する。ホバーは形を変えず、即時に色だけを変える。

高さ30px以下の名前背景は従来の細い塗りを維持する。それより高い背景では、高さに応じて筆跡を太くする（太さの基準は `4 + (高さ - 30) × 0.55` px、最大30px）。太い筆跡を重ね、左右の塗り終わりをそれぞれ独立してずらす。大きな面では矩形の下塗りを使わず、輪郭を太いクレヨンの跡そのもので形成する。表示寸法とクリック範囲は変えない。

左右端だけ、切り込みの数・深さ・位置を筆跡ごとに変える。上下の辺は直線のままにする。質感は既存と同程度の小さな透明粒を追加し、左右の始点・終点に近いほど密度を高め、上下辺にも少量加える。透明度グラデーションや帯状の消去は使用しない。

端のかすれは筆跡単位の作業用Canvasで付けてから全体へ重ねる。完成後の背景から各筆跡の端を消すと、下の筆跡まで消えてボタン内部に薄い帯が生じるため、その方法は使わない。作業用Canvasは生成中だけ再利用する。粒・かすれは生成時だけ計算し、演出フレームごとには再計算しない。

筆跡が1本だけの領域には、既存と同程度の小さな透明粒を追加する。2本以上が重なる部分にはこの追加分をかけず、相対的に少し濃く見せる。かすれを付ける前の筆跡形状から被覆・重複マスクを作り、3本以上の重なりも重複として保持する。帯状の透明化は行わない。追加粒の候補数は面積/12、透明化の強さは0.12～0.40で、マスク計算も生成時のみ行う。

`setFillStyle` は顔料の色、`setStrokeStyle` は顔料を明るくするアクセントとして扱う。実際の色が変わると形を再生成して描き替える。同じ色の再設定だけでは演出を繰り返さない。幾何学的な枠線は描かず、ボタンの中心・表示寸法・矩形のクリック範囲は維持する。

## 描き替え演出と設定

`src/data/ui.ts` の `CRAYON_ANIMATION.redrawDuration` で背景全体の描き替え時間を秒単位で設定する。既定は0.25秒、0なら即時切替、負数は0として扱う。PhaserのTweenを使い、Ctrlキーの2倍速にも追従する。コンフィグツールの「UI演出」タブで編集できる。

古い塗りの消去と新しい塗りの描画は同時に進める。生成時の筆跡形状をマスクに使い、上の筆跡から順に、各筆跡の始点から終点へ左から右に走査する。隣接する筆跡の進行時間を少し重ね、全筆跡を設定時間内に描き終える。途中で再変更された場合は、その時点の表示を取り込んで次の描き替えへつなぎ、古い完成形へ巻き戻さない。新しい筆跡形状の外に残った旧形状や細い名前背景の下塗りには、筆跡の中心間で分けた帯域の走査を併用し、消し残しを防ぐ。

敵行動予告は背景を破棄せず再利用する。行動キー・表示文字・数値・配色が変わったときに一度再生成し、変更のないHUD更新では演出を繰り返さない。表示文字は直ちに更新し、背景だけを描き替える。

ホバーには `setHoverColor(色)`、解除には引数なしの `setHoverColor()` を使う。短時間に出入りしても筆跡の生成やTween開始は行わず、現在の表示フレームを即時に着色する。描き替え途中でも進行を保ち、解除時は本来の色へ戻す。End Turnが無効になったときはホバー色を解除し、無効色への描き替えを表示する。

## 配色と適用範囲

- プレイヤー名：深い青。敵名：深い赤。
- 敵行動予告：黒。プレイヤーへのEP攻撃を含む行動は紫を優先（HP/EP複合攻撃も紫）。文字にも同系色の細い縁を付け、HP/EPの数値色は維持する。
- 通常ボタン：青灰色、ホバーで明るくなる。End Turnは従来の橙色・黒文字と、無効時の灰色を維持する。
- タイトル、戦闘、報酬、敗北画面の設定・確認・戻る等のボタン、山札/捨て札の操作・並べ替え・閉じるボタン、敗北イベントのADV操作ボタンへ適用。
- エナジー欄と手札枚数にも同じ質感を使用。敗北イベントのプレイヤー名にも青い背景を使用。
- カード本体、レリック/状態アイコン、HP/EPバー、Tips、デバッグ操作ボタンは既存の表現を維持する。

`paintBehindLabel` はルートにあるHUD文字に背景を追従させる。名前や枚数の文字幅に合わせて背景を更新し、文字が隠れれば背景も隠し、文字の破棄時に背景と更新イベントも破棄する。文字をコンテナへ移動しないため、スプライト切替や敵のクリック範囲・レティクルの座標計算を変更しない。

## Tipsの今後の検討（未実装）

枠線をなくし、文章領域を少し斜めの暗いクレヨン背景で覆う方針が合う。長文の可読性を優先し、文字の直下は密に塗り、擦れを主に外周へ寄せる。本文自体は傾けず、既存の折返し・高さ計算・ホバー待ち時間をそのまま使用する。複数行を1本の細い塗りで覆うと下地が透けるため、段落全体の背面に十分な面積を確保する。
