# クレヨンUIの描画方針

## 共通部品

`src/ui/crayon.ts` の `CrayonPatch` を名前・行動予告・ボタンの背景に使用する。白いクレヨンの塗りをCanvasでサイズ別に描画し、PhaserのTintで着色する。中央は文字の可読性を保てる濃さにし、輪郭の欠け、斜めの塗り端、細かな塗り残しで四角いベタ塗りを避ける。

同じ寸法のテクスチャはゲーム内で共有する。乱数は寸法に基づくローカルな生成器を使い、ゲームの抽選結果に影響を与えない。ホバー・無効化では色だけを変え、テクスチャは再生成しない。

高さ30px以下の名前背景は従来の細い塗りを維持する。それより高い背景では、高さに応じて筆跡を太くする（太さの基準は `4 + (高さ - 30) × 0.55` px、最大30px）。太い筆跡を重ね、左右の塗り終わりをそれぞれ独立してずらす。大きな面では矩形の下塗りを使わず、輪郭を太いクレヨンの跡そのもので形成する。表示寸法とクリック範囲は変えない。

`setFillStyle` は顔料の色、`setStrokeStyle` は顔料を明るくするアクセントとして扱う。従来のボタンのホバー・無効化・エナジー回復時の強調処理から呼び出せるが、幾何学的な枠線は描かない。ボタンの中心・表示寸法・矩形のクリック範囲は維持する。

## 配色と適用範囲

- プレイヤー名：深い青。敵名：深い赤。
- 敵行動予告：黒。プレイヤーへのEP攻撃を含む行動は紫を優先（HP/EP複合攻撃も紫）。文字にも同系色の細い縁を付け、HP/EPの数値色は維持する。
- 通常ボタン：青灰色、ホバーで明るくなる。End Turnは従来の橙色・黒文字と、無効時の灰色を維持する。
- タイトル、戦闘、報酬、敗北画面の設定・確認・戻る等のボタン、山札/捨て札の操作・並べ替え・閉じるボタン、敗北イベントのADV操作ボタンへ適用。
- エナジー欄と手札枚数にも同じ質感を使用。敗北イベントのプレイヤー名にも青い背景を使用。
- カード本体、レリック/状態アイコン、HP/EPバー、Tips、デバッグ操作ボタンは既存の表現を維持する。

`paintBehindLabel` はルートにあるHUD文字に背景を追従させる。名前や枚数の文字幅に合わせて背景を更新し、文字が隠れれば背景も隠し、文字の破棄時に背景と更新イベントも破棄する。文字をコンテナへ移動しないため、スプライト切替や敵のクリック範囲・レティクルの座標計算を変更しない。

## Tipsの今後の検討（未実装）

枠線をなくし、文章領域を少し斜めの暗いクレヨン背景で覆う方針が合う。長文の可読性を優先し、文字の直下は密に塗り、擦れを主に外周へ寄せる。本文自体は傾けず、既存の折返し・高さ計算・ホバー待ち時間をそのまま使用する。複数行を1本の細い塗りで覆うと下地が透けるため、段落全体の背面に十分な面積を確保する。

## 確認

日英のタイトル・戦闘・設定・山札一覧・報酬と敗北画面を確認する。操作変更時は `tests/keyboard-speed.cjs`、敵HUDの背景変更時は `tests/enemy-selection.cjs` でキー操作・クリック範囲・敵切替後の破棄を確認する。
